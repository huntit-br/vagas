## 🔔 Como ser avisado de Novas Vagas

Não perca nenhuma oportunidade! Para receber notificações em tempo real sempre que uma nova vaga for publicada:
1. No topo direito desta página, clique no botão **`Watch`**.
2. Selecione **`Custom`** ➔ marque **`Issues`** (ou selecione **`All Activity`**).
3. Pronto! Você receberá notificações diretamente no seu e-mail e aplicativo do GitHub a cada nova vaga aberta.
